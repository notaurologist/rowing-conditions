# 0003: Hono for the API

Status: Accepted (October 2026)

## Context
Candidates were Hono and Fastify. Fastify is older and more established with a large plugin ecosystem. Hono is newer but popular, built on web standards, and includes a typed client that infers types from server routes with no code generation.

## Decision
Use Hono on Node, exporting the app type for `hono/client`.

## Consequences
- Web and future mobile clients get end-to-end types over plain REST.
- Smaller ecosystem than Fastify; Hono changes faster, so agents should check the installed version's docs.
- Fastify remains a reasonable fallback if Hono becomes a problem.
